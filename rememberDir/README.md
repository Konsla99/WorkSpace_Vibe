# rememberDir

Windows 파일 탐색기의 모든 폴더 경로를 기록하고, 나중에 한 번의 클릭으로 탭 형태로 완벽하게 복원하는 유틸리티입니다.

## 프로젝트 구조
- `src/`: C# 소스 코드 및 프로젝트 파일
- `docs/`: 기획 문서 및 개발 기록
- `build.bat`: 윈도우용 자동 빌드 스크립트
- `bin/`: 빌드 완료된 실행 파일이 저장되는 곳 (빌드 후 생성됨)

## 주요 기능
- **현재 dir 기록하기**: 현재 열려 있는 모든 파일 탐색기 창과 탭의 경로를 수집하여 `%LOCALAPPDATA%\rememberDir\state.json`에 저장합니다. (다중 창 및 다양한 탐색기 환경 지원 강화)
- **마지막 dir 위치 열기**: 저장된 경로를 바탕으로 파일 탐색기를 실행하고, Windows 11의 경우 여러 탭을 자동으로 생성하여 복원합니다. (좌우 배치 UI로 접근성 향상)

## 업데이트 내역
- **UI 레이아웃 변경**: 버튼을 좌우 병렬 배치로 변경하여 사용성을 높였습니다.
- **경로 수집 로직 개선**: 창이 3개 이상일 때 누락되던 문제를 해결하고, 탐색기 식별 로직을 강화했습니다.
- **사용자 가이드 추가**: 복원 중 오작동 방지를 위한 시각적 경고 문구를 GUI에 추가했습니다.
- **배치 파일 개선**: 빌드 및 배포 스크립트의 안정성을 높였습니다.

## 빌드 및 배포 방법 (Windows)

1. **필수 소프트웨어**: [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) 설치.
2. **빌드 실행**: 루트 폴더의 `build.bat` 파일을 더블 클릭합니다.
3. **결과 확인**: 루트 폴더에 생성되는 `bin/rememberDir.exe` 파일을 사용합니다.

## 주의 사항
- Windows 11의 탭 복원 기능은 키보드 자동 입력을 사용하므로, 복원 중에는 컴퓨터 조작을 잠시 멈춰주세요. (GUI 내 경고 메시지 확인 권장)
- 네트워크 드라이브나 삭제된 경로는 자동으로 건너뜁니다.
